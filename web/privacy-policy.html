이 방침은 모임 날짜를 조율하는 날모아 웹사이트와 Android 앱에 적용됩니다. 날모아는 만 13세 이상을 대상으로 하며, 계정 생성이나 로그인 없이 이용할 수 있습니다.

처리하는 정보와 이용 목적

  • 모임을 만들 때 모임 이름, 설명을 입력한 경우 그 내용, 후보 날짜를 서버에 저장합니다. 모임 링크를 발급하고 모임 화면과 날짜별 결과를 제공하기 위해 사용합니다.
  • 응답을 제출할 때 참여자가 입력한 이름 또는 별명과 선택한 날짜를 서버에 저장합니다. 날짜별 가능한 인원과 참여자 이름을 보여주기 위해 사용합니다.
  • 응답을 수정할 수 있는 키를 기기의 앱 또는 브라우저에 저장합니다. 응답을 저장하거나 수정할 때 이 키를 HTTPS로 서버에 보내고, 서버에는 키의 해시를 저장해 수정 권한을 확인합니다.
  • 호스팅 서비스의 기본 운영 로그에는 연결 정보와 요청 방식·경로, 응답 상태, 처리 시간, 브라우저 정보 등이 기록될 수 있습니다. 이 정보는 서비스 운영 및 오류 진단에 쓰입니다. 날모아는 광고, 별도의 사용자 행동 분석 도구, 운영 로그의 외부 내보내기를 사용하지 않습니다.

모임 정보 공개 범위

초대 링크를 가진 사람은 별도 로그인 없이 모임 이름, 설명, 후보 날짜, 응답자의 이름과 선택 날짜를 볼 수 있습니다. 링크를 전달받은 사람도 같은 정보를 볼 수 있으므로 입력란에 민감한 정보를 적지 마세요. Android 공유 기능을 사용하면 사용자가 선택한 앱에 초대 링크가 전달됩니다.

호스팅과 정보 보호

웹 화면은 GitHub Pages에서 제공하고, 모임과 응답을 처리하는 API 및 데이터베이스는 Supabase에서 운영합니다. 기기에서 웹과 API로 보내는 정보는 HTTPS로 전송합니다. 서버는 응답을 수정할 때 수정 키를 확인합니다.

보관과 삭제

모임과 응답 데이터에는 현재 고정된 보관 기간이나 자동 만료 기능이 없습니다. 모임과 응답은 운영자가 제거하기 전까지 서버에 보관됩니다. 호스팅 운영 로그에는 각 제공업체의 보관 기준이 적용됩니다. Supabase 기본 로그의 보관 기간은 프로젝트 요금제에 따라 달라집니다.

앱을 삭제하거나 기기에서 앱 또는 브라우저 데이터를 지우면 기기에 있던 응답 수정 키가 지워집니다. 이렇게 해도 서버에 저장된 모임과 응답은 지워지지 않습니다. 날모아에는 모임이나 응답을 직접 삭제하는 기능 또는 별도의 데이터 삭제 요청 절차가 없습니다.
